## 三、問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

在測試一中，桌遊整理後的串列為 `['amy', 'ben', 'amy', 'cora']`，雖然長度是 4，但 `'amy'` 出現了兩次，代表同一位參加者重複填報或被重複登記。依照活動規則，同一個人在同一場活動重複出現只算一位參加者、只收一次費用，因此實際參加桌遊的人只有 `amy`、`ben`、`cora` 共 3 位，費用應以 3 人計算（`3 × 120 = 360.00` 元）。

* **直接把字串拆成 `list`**：
  * **保留了什麼**：保留了原始填報的先後順序，也保留了重複出現的次數（能看出誰重複報名或總共切出幾筆紀錄）。
  * **失去了什麼**：沒有自動去重，若直接用 `len(list)` 算人數或算錢，會把重複登記同一場的人誤算成多人。
* **再轉成 `set`**：
  * **保留了什麼**：保留了「有哪些不重複的參加者」，方便後續做交集、聯集與差集等集合比對，也符合單場去重計費的規則。
  * **失去了什麼**：失去了原本的排列順序與重複次數資訊，且元素無法用索引取值（若要固定順序顯示，還需要另外用 `sorted()` 排序）。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

在測試三裡，桌遊去重後是 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影去重後也是 $M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$。因為兩場去重後的名單一模一樣，所以 $B = M$，交集跟聯集也都剛好是這 3 個人：

- 交集（兩場都報）：$B \cap M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，共同人數 $|B \cap M| = 3$。
- 聯集（至少報一場）：$B \cup M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，總不重複人數 $|B \cup M| = 3$。

「報名人次」算的是兩場各自去重後加起來有幾筆報名紀錄，一個人如果兩場都報，桌遊算 1 次、電影算 1 次，所以是：

$$\text{報名人次} = |B| + |M| = 3 + 3 = 6\text{（人次）}$$

至於費用是兩場分開算（桌遊每人 120 元、電影每人 80 元）：

$$\text{桌遊應收} = 3 \times 120 = 360.00\text{（元）}$$

$$\text{電影應收} = 3 \times 80 = 240.00\text{（元）}$$

$$\text{總應收} = 360.00 + 240.00 = 600.00\text{（元）}$$

所以雖然實際上只有 3 位不同的人，但因為這 3 位都兩場全包，加起來就會變成 6 人次，總應收也一樣是 600.00 元。
